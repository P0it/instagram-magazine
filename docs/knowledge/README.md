# 레퍼런스 전문가 지식

`.claude/agents/ref-*.md` 에이전트들이 작업 전에 읽고 작업 후에 갱신하는 누적 노트다. 레퍼런스(캐러셀 1건)가 늘수록 관찰이 쌓이고 원칙이 다듬어진다.

| 파일 | 담당 에이전트 | 내용 |
|---|---|---|
| `curator.md` | ref-curator | 주제·각도·톤·시리즈 |
| `marketer.md` | ref-marketer | 훅·구성·저장 트리거·반응 |
| `uiux.md` | ref-uiux | 레이아웃·위계·색·템플릿 후보 |
| `market.md` | ref-market-researcher | 장르·계정 수집 현황 |

규칙: 표본 수(N)를 항상 적는다. N<10 인 원칙은 "후보"다. 남의 이미지·문구는 옮기지 않고 구조만 기록한다.
