# UI/UX 노트
N=7. **모든 원칙은 후보.** 템플릿 후보는 `src/presets/templates.ts` 로 옮길 때 구조만 쓴다.

## 표지 레이아웃 유형
| 유형 | 건수 | 특징 |
|---|---|---|
| 사진 풀블리드 + 하단 어두운 그라데이션 + 흰 굵은 제목 | 3 | 책·영화·맛집. 핵심 단어만 노랑/형광 |
| 색 면/박스 제목 (하이라이트 박스·테두리 박스) | 3 | 뉴닉(주황 박스, 흰 박스+검정 테두리), 청년서가(파랑 띠+회색 박스) |
| 검정 배경 + 작품/오브제 콜라주 + 라벨 칩 | 1 | kketalk (빨강 라벨 + 흰 제목) |

## 본문 유형
- 상단 사진 + 하단 흰/연한 영역에 번호 라벨 + 본문 (뉴닉)
- 어두운 배경 + 노랑 제목 + 흰 설명 + 대상 이미지 1개 + 코너 원형 인물 (feelmbook)
- 컷 3분할 + 작품 정보 + 인용 한 줄 (Knot.)
- 흰 바탕 2×2 사진 카드 + 이름/위치/설명 (mens_now_)

## 템플릿 후보 (구조만)
1. **사진 풀블리드 + 하단 제목 2~3줄** (+ 키워드 형광 강조)
2. **번호 라벨 + 본문 하단 영역** (상단 사진 55% / 하단 흰 영역)
3. **2×2 정보 카드 격자** (사진 + 굵은 이름 + 작은 위치 + 한 줄)
4. **색 박스 제목 + 사진 배경** (주황/핑크 계열)
- 현재 18개 내장 템플릿에 2~4번은 없음 → 추가 후보.

## 색 (관찰된 포인트)
- 주황 계열(뉴닉), 형광 노랑(책), 진한 파랑+연두 스티커(청년서가), 검정+빨강 라벨(kketalk).
